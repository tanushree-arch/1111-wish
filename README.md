# 11:11 Wish Website

A small, editable multi-page website built with plain HTML, CSS and JavaScript.

## Project structure

- `index.html` — opening 11:11 chat-style page
- `flowers.html` — bouquet page with a gentle sway animation
- `secret.html` — placeholder for the secret/code reveal
- `thankyou.html` — final thank-you page
- `css/style.css` — shared styling for all pages
- `js/main.js` — opening-page navigation
- `assets/bouquet.png` — bouquet image

## How to run

1. Extract the ZIP.
2. Open the `1111-wish-project` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Click the opening chat bubbles to move to the flower page.

## How we'll add pages later

Create a new `.html` file in the project folder, link it from the previous page, and add any shared styles to `css/style.css`. Keep images inside `assets/`.

The secret and thank-you pages are intentionally placeholders so we can edit them together later.
